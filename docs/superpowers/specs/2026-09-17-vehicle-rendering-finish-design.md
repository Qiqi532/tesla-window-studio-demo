# 车模原厂写实渲染收尾设计

日期：2026-09-17

## 目标与范围

在不修改或替换 `public/assets/tesla-model-3-2018.glb` 的前提下，修正前后灯、门把手与前进气口的运行时材质，使整车接近 2018 Model 3 的原厂写实观感。保留已经完成的石墨灰内饰、烟熏玻璃、轮毂纹理、AgX 色调映射、道路天气和夜景能力。

本阶段不实施长句多指令语音，不修改 Whisper、R2、Cloudflare 配置，也不向 GitHub 推送。长句语音沿用 `docs/2026-09-17-语音多指令开发计划.md`，待渲染验收后另行确认。

## 已确认问题

- 源 GLB 的受控灯具材质包含底色贴图和部分发光贴图；当前运行时实现将这些贴图替换为纯色物理材质，导致灯罩亮度提高但反射碗、灯带和内部纹理层次丢失。
- `tembus_red.0` 是前后灯共用的透明罩材质，需要按车辆前后位置分别创建透明罩，但不应覆盖内部灯具的原始纹理。
- 门把手应跟随车漆，并保留略有区别的清漆高光。
- 前进气口和下部包围应保持接近中性石墨黑；仅允许极弱的车漆环境色影响，不能直接按车漆染色。
- 夜景的光束和 Bloom 只能强化已开启的灯具，不能让关闭灯具或车身高光泛白。

## 方案设计

### 1. 灯具材质分层

灯具继续使用现有模型几何，不创建替代模型。运行时分为三类职责：

1. 外层灯罩：仅对 `tembus_red.0` 按前后位置创建 `MeshPhysicalMaterial`。前罩使用低饱和冷灰透明层，后罩使用深红透明层；深度写入关闭、固定渲染顺序、不投射阴影。
2. 内部灯面：受控灯具保留源 `map`、`emissiveMap`、透明度和 UV，通过克隆源材质再调整颜色、粗糙度、金属度、清漆与环境反射，不再创建丢弃贴图的纯色材质。
3. 反射碗与壳体：保留贴图，使用较高金属度和中等粗糙度形成内部明暗层次；被动反光面在关闭状态不得自发光。

关闭状态只保留灯罩本色和极弱环境反射，发光强度为零。开启状态只提升受控灯面和对应外罩的发光，不修改底色贴图，因此灯罩轮廓与内部纹理始终可辨认。

### 2. 灯光与后期效果

- 白天及影棚仅使用受控灯面与现有聚光灯，不显示空气光束，不启用全屏 Bloom。
- 夜景保留局部灯光、地面光池和低强度光束；Bloom 使用高阈值和低强度，仅捕捉真正高亮的灯面。
- 前灯使用略暖的白色，雾灯更暖；尾灯和刹车灯保持饱和红色，刹车灯亮度高于尾灯；倒车灯保持中性白色。
- 所有强度仍由一个配置源控制，避免材质、聚光灯、光束和 Bloom 各自出现重复魔法数值。

### 3. 门把手与前脸饰件

- 门把手使用独立克隆材质，颜色跟随车漆，粗糙度比车身略高、环境反射略低，以保持轮廓而不形成白边。
- 前进气口、下部包围和轮拱不再跟随车漆着色，统一使用中性石墨黑；保留源贴图，以粗糙度和环境反射表现凹陷与塑料层次。
- 只有经模型节点和材质审计确认属于外部把手的材质才跟随车漆，不能把内饰门板误归入车漆联动组。

## 数据流与兼容性

`loadVehicle()` 的顺序保持为：加载 GLB → 审计节点与材质 → 规范化静态显示材质 → 克隆所有会被控制器修改的材质 → 建立材质索引 → 返回原控制器结构。

车窗、车门、备箱、轮轴、车漆、轮毂与灯光控制接口保持不变。渲染配置继续由 `renderProfile.js` 集中提供；控制器只根据车辆状态更新灯面发光、聚光灯、光束与外罩，不拥有环境参数。

如果运行时遇到未分类材质、灯罩无法判断前后位置、或灯组没有取得实际正在渲染的克隆材质，加载立即失败并显示现有错误遮罩，不静默回退为白色材质。

## 验证范围

自动验证保持基础且有针对性：

- 模型 SHA-256、节点、网格、材质、必需控制节点和材质角色清单通过。
- 单元测试确认灯面保留 `map`/`emissiveMap`、关闭状态不发光、开启时只影响实际渲染克隆；前后灯罩独立；门把手随车漆；进气口保持中性石墨黑。
- 执行测试、生产构建和 `git diff --check`。
- Cloudflare 先发布唯一预览地址，核对 HTML、JS、GLB 状态及 GLB 哈希；用户在网页端负责六镜头、天气与灯光的最终视觉验收。
- 只有用户明确确认预览后，才向 Pages 生产分支直接部署；全程不使用 GitHub。

## 验收标准

- 前后灯关闭时不出现白片、纯色塑料块或自发光；开启时有清晰灯带、反射碗、外罩与颜色层次。
- 夜景灯光有有限的光池和光晕，不出现覆盖车身的雾状光锥。
- 门把手随车漆但仍能从门板上辨认；前进气口为有纹理和凹陷感的石墨黑，而不是车漆色或死黑色块。
- 所有镜头下车身、玻璃、灯具、四轮和可动部件完整；既有控制功能与语音单指令功能不回归。
