### 3.4 本地语音模型（R2 端到端）

链路上有一处**致命缺陷**，已修复：

```
原： env.remotePathTemplate = '{model}/{revision}/{file}'
     → 实际请求 https://.../asr/Xenova/whisper-tiny/<rev>/{file}/tokenizer_config.json  → 404
     → 反馈"本地语音模型未能加载"，"本地识别"完全不可用

改： env.remotePathTemplate = '{model}/{revision}/'
```

原因：`@huggingface/transformers@3.8.1` 内部按 `remoteHost + 模板(替换 model/revision) + 文件名` 拼接，模板本身必须以斜杠结尾且不含 `{file}` 占位符。

修复后验证：

| 项 | 结果 |
|---|---|
| worker 从 R2 拉取的文件 | 12/12（含 `onnx/encoder_model_quantized.onnx`、`onnx/decoder_model_merged_quantized.onnx`） |
| 浏览器缓存 | `transformers-cache` 中 7 条 R2 记录（首次下载后全部命中） |
| 模型就绪耗时 | **2.3 s**（缓存命中时） |
| 首次下载耗时 | 约 40 MB / 150 s 左右（取决于到 R2 的链路） |
